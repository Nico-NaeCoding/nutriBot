## 📌 Overview

**NutriBot**은
사용자의 신체 정보(성별, 나이, 키, 체중 등)를 기반으로 맞춤형 식단을 추천하고 영양 상담을 제공하는 AI 챗봇 서비스입니다.

단순한 챗봇이 아닌

* 👤 사용자 신체 정보 기반 개인화
* 🤖 OpenAI API 기반 자연어 상담
* 🥗 맞춤형 식단 추천
* 💬 대화형 인터페이스 제공

을 결합하여

👉 **사용자가 자신의 건강 상태와 목표에 맞는 식단 정보를 쉽고 자연스럽게 얻을 수 있는 서비스**를 만드는 데 초점을 맞췄습니다.

## ✨ Features

### 👤 User Profile

* 성별, 나이, 키, 몸무게 입력
* 사용자 프로필 정보 관리
* 개인화된 상담을 위한 정보 반영

---

### 🤖 AI Diet Consultation

* OpenAI API 기반 식단 상담
* 건강 및 영양 관련 질의응답
* 자연어 기반 대화형 인터페이스

---

### 🥗 Personalized Recommendation

* 사용자 신체 정보 기반 식단 추천
* 건강 상태를 고려한 맞춤형 조언
* 개인화된 식단 예시 제공

---

### 💻 User Experience

* 실시간 채팅 인터페이스
* 직관적인 사용자 입력 UI
* 반응형 웹 지원
